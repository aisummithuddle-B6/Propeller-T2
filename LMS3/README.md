# Functional Documents - Corporate Learning Progress, Intervention & Compliance Tracking System

## Product Scope

This document set describes a focused corporate learning tracking product. It is not a full Learning Management System (LMS). The product consolidates learning attendance, assessment scores, and competency milestones; identifies at-risk learners using configurable rules; tracks interventions; and produces compliance-ready reports.
