# Dashboards, Reports, and Compliance

## Dashboard Principles

- Dashboards should support decisions and action, not only display metrics.
- Every dashboard metric should allow drill-down to learner, program, competency, or intervention detail where appropriate.
- Risk indicators should show reasons, not just labels.
- Compliance reports should be reproducible and auditable.

## Dashboard 1: Learning Risk Overview

Primary users:

- L&D Administrator
- Trainer
- Manager

Metrics:

- Total active learners.
- Number and percentage of at-risk learners.
- Risk distribution by low, medium, high, and critical.
- At-risk learners by program.
- At-risk learners by department or manager.
- Top triggered risk rules.

Filters:

- Date range
- Program
- Department
- Manager
- Location
- Risk level
- Competency

Actions:

- Open learner profile.
- Create intervention.
- Export risk list.

## Dashboard 2: Competency Progress

Primary users:

- Trainer
- L&D Administrator
- Compliance Officer

Metrics:

- Competencies completed.
- Competencies in progress.
- Overdue competencies.
- Completion trend by week or month.
- Competency completion by program, department, and role.

Actions:

- View overdue learners.
- View competency evidence.
- Generate compliance report.

## Dashboard 3: Assessment Performance

Primary users:

- Trainer
- L&D Administrator

Metrics:

- Average assessment score.
- Pass/fail rate.
- Repeated failed attempts.
- Score distribution.
- Learners below threshold.

Actions:

- Create coaching intervention.
- Assign reassessment.
- Export low-score learners.

## Dashboard 4: Attendance Gaps

Primary users:

- Trainer
- L&D Administrator
- Manager

Metrics:

- Average attendance percentage.
- Learners below attendance threshold.
- Missed sessions.
- Attendance trend by session or program.

Actions:

- Schedule remedial session.
- Notify manager.
- Add attendance correction request.

## Dashboard 5: Intervention Tracker

Primary users:

- Trainer
- Manager
- L&D Administrator

Metrics:

- Open interventions.
- Overdue interventions.
- Completed interventions.
- Outcome distribution.
- Improvement after intervention.

Actions:

- Update intervention status.
- Record outcome.
- Escalate overdue intervention.

## Compliance Reports

## Report 1: Mandatory Training Compliance Report

Purpose: Show whether employees completed required training and competency milestones.

Includes:

- Employee details.
- Program details.
- Required competencies.
- Attendance status.
- Assessment status.
- Completion status.
- Exceptions or waivers.
- Evidence references.

## Report 2: At-Risk Learner Report

Purpose: Provide a list of learners requiring attention.

Includes:

- Employee details.
- Risk level.
- Triggered rules.
- Risk reason.
- Program and competency.
- Assigned intervention status.

## Report 3: Intervention Effectiveness Report

Purpose: Measure whether interventions improve learning outcomes.

Includes:

- Intervention type.
- Assigned owner.
- Pre-intervention risk level.
- Post-intervention status.
- Assessment or attendance improvement.
- Outcome notes.

## Report 4: Audit Evidence Report

Purpose: Provide evidence for internal or external audit.

Includes:

- Report generation date.
- Filters used.
- Data source references.
- Rule versions used.
- Attendance records.
- Assessment records.
- Competency evidence.
- Intervention history.

## Export Requirements

- Reports should export to CSV and PDF.
- Exported reports should include generated date, generated by, applied filters, and data timestamp.
- Sensitive fields should be masked or excluded based on role permissions.
- Export activity should be audit logged.

## Compliance Considerations

- Maintain traceability from report values to source records.
- Preserve historical rule versions used for past risk classifications.
- Track manual corrections and exceptions.
- Protect personal and sensitive employee data.
- Retain records according to organizational and regulatory policies.
